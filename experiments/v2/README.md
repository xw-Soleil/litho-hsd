# V2：固定协议下的去重重跑

V1 的分数可以从保存的预测复算，但原始图像哈希检查遗漏了裁剪、黑边、D4 变换和不同邻域之间的重复；EVAL 还被用于选择 few-shot 分类器。V2 保留旧训练产物，重新建立数据协议并从头训练。V2 不与 V1 或文献的不同测试集直接排名。

## 数据协议

固定种子为 `20261031`。将同一官方测试邻域、相同原图哈希、相同 D4 规范化 masked120 输入连接为一个组件。使用 masked120 键也检查普通 dens/squish 实验，以避免仅因训练图保留外围内容而漏掉裁剪重复。

- 含官方训练图的组件：官方训练图按组件分到 TRAIN/VAL；其中的官方测试图全部排除。
- 仅含官方测试图的组件：约 20% 分到 SUPPORT，20% 分到 TUNE，60% 分到 TEST。稀有类别为 SUPPORT/TUNE 保留至少 5 个文件（可行时）；实际比例和唯一图形数以审计为准。
- 组件不跨有效数据分区。排除的样本与类别分布写入审计，不能把过滤后的基准称为原始 ICCAD 标准测试集。
- `manifest.csv` 保存原始缓存行号、路径、标签、分区、组件、重复键和排除原因。训练入口检查路径/标签与缓存完全一致，并将 manifest 的 SHA256 写入每次训练日志。

这项检查覆盖完全相同的图像、统一裁剪后相同的输入和 D4 等价输入，不证明不存在任意平移或局部空间重叠。旧版已探索过整份数据；重新固定协议不能撤销历史上的数据接触，因此新结果称为“固定协议下的审计重跑”，不称为未接触过的外部盲测。

## 固定方法与标签预算

具体设置在 `plan.json` 中，在正式训练前确定。

| 方法 | 更新模型权重的数据 | 适配/调参数据 |
|---|---|---|
| 二分类 CNN | TRAIN，HS/NHS | 双阈值只在 TUNE 搜索 |
| 元学习原型网络 | TRAIN，HS/NHS，按设计×类别构造 episode | 三类原型只使用 SUPPORT |
| CNN 特征 + 原型/kNN 对照 | 与二分类 CNN 相同 | 与元学习模型使用完全相同的 SUPPORT 行号 |
| 全监督三分类参考 | TRAIN + SUPPORT | 固定训练步数，不按 TEST 选 epoch |
| 不用 NNHS 标签的原型距离拒识 | TRAIN | 距离阈值仅使用 VAL |

主要表示为 `densm`，训练种子为 0、1、2。主 few-shot 设置为每个设计每类 5 个不同 `dup_key` 的标签、原型分类、30 次固定支持集抽样；不足时明确报告实际数量。K=1/10/20 和 kNN(15)、每类最多20/100标签为事先规定的辅助分析。

普通 CNN 特征为 256 维，元学习模型投影为 128 维；训练目标和优化样本量也不同。因此，这是两套训练方案的实用对照，不能把差异完全解释为元学习损失单一因素的因果效果。日志保留步数、样本访问量和计算时间。

## 跨工艺节点

所有 `holdout=iccad1` 模型的训练和训练监控都排除 iccad1。支持样本来自 iccad1 的 TRAIN，目标为所有不含官方训练图的组件中的 iccad1 测试中心图（`cross_target`）。这是独立声明的二分类迁移任务，目标集合不等于三分类 TEST。

报告同时列出不用目标标签的 CNN，以及同样 K 个目标标签的 CNN 特征/元学习特征原型分类。主要对照是后两者。报告 HS 召回率、误报数、误报率和 AUC，不将 HS 召回率称为整体准确率。32nm 只有一个设计，不能据此宣称所有工艺迁移均有优势。

## 运行与产物

正式训练使用 `ssh xlab01` 进入的集群，通过 Slurm GPU 作业运行。远程工作目录为 `~/work/dtco/v2/`，复用 `~/work/dtco/cache/` 和已有 venv。训练会保存可恢复 checkpoint；只有模型、预测、嵌入和日志全部写入且通过哈希校验后才生成完成标记。

本地训练产物在 `runs/v2/`，新报告和图在 `results/v2/`。`slurm/sync_v2.sh` 只同步 V2；`--models` 额外取回最终权重。原有 `runs/` 子目录和 `results/RESULTS.md` 属于 V1，不用于新结果汇总。

运行状态与本地产物核验见 `execution.json`。从保存的逐样本预测独立复算，主结果与跨节点结果均与报告一致。若换平台从 float32 嵌入重算分类，近乎并列的相似度可能因数值舍入改变极少量预测；本次本机抽查最多出现 48,114 张中的 2 张差异。精确核对已报告数字应使用保存的预测，跨平台重新计算不承诺逐位一致。

`manifest.csv` 含课程数据派生路径与标签，不纳入 Git；完整生成代码、协议设置和汇总审计供本地复现。课程最终报告应按课件要求说明开源代码/AIGC使用和成员贡献。
